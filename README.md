# hxyfront-62008 烟花燃放脚本编排

源提示词编号：10

我想做一个面向烟花燃放编排师的燃放脚本前端工具，可以记录节目段落、烟花型号、口径、发射角度、点火时间、持续时间、安全距离和音乐时间点。页面需要有时间轴编排、燃放点位平面图、型号清单、冲突时间提示和整场节目预览。

## 技术栈

React + Vite + TypeScript

## 整场预演

- **按点火时间推进**：预演引擎按点火时间排序逐枚模拟；同一燃放点位前一枚尚未结束、同点位安全间隔不足，或发射窗口重叠时点位间距小于有效安全半径（随发射角度增大），立即停在冲突节点，原稿不被修改。
- **从节点重跑**：调整节点发射角度或更换点位后，整场预演被锁定，只能从该节点（多次改动取点火时间最早者）重跑；起点之前的节点视为已按原稿燃放，仅用于恢复点位占用状态。
- **整次拒绝**：音乐时间点越界（超出曲目总长）或引用的段落已移除时，整次预演被拒绝并列出全部原因，不产生快照。
- **快照恢复**：每次推进（通过或停在冲突节点）都会把最近预演快照写入 localStorage，刷新后时间轴、点位图、冲突清单同步恢复；脚本变更后快照标记为“基于旧稿”。

### 代码结构

- `src/domain/model.ts` — 领域模型：脚本、节点、点位、段落、音乐时间点与安全规则常量
- `src/domain/rehearsal.ts` — 冲突校验与预演推进引擎（纯函数）
- `src/storage/snapshotStore.ts` — 最近预演快照的本地持久化
- `src/components/` + `src/App.tsx` — 页面接入：时间轴、点位平面图、冲突清单、节点编辑
